# 기업조사 Chrome 확장 — 손영훈 (HW6 prototype)

Spec: `docs/specs/손영훈-company-research.md` (P0만 구현)

## 설치 (개발자 모드)

1. 이 저장소를 내 컴퓨터에 받는다 (`git pull`).
2. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`prototypes/손영훈/`)를 선택.
4. 확장 아이콘(퍼즐 모양)에서 "SDR 기업조사"를 고정한다.
5. 확장 카드의 **세부정보 → 확장 프로그램 옵션**에서 Gemini 키와 DART 키를 넣고 저장.
   키는 내 Chrome 안에만 저장된다. 이 폴더나 저장소에는 키를 넣지 않는다.

## 쓰는 법

1. 조사할 회사의 웹사이트를 탭에서 연다.
2. 확장 아이콘을 누르면 오른쪽에 사이드 패널이 열리고, 주소가 자동으로 채워진다.
3. 회사명(DART 검색용)을 넣고 **조사**.
4. DART 후보가 여러 개면 하나를 고른다.

처음 DART를 쓸 때는 회사 목록(수 MB)을 한 번 받느라 몇 초 걸린다. 이후 30일 동안은 저장된 목록을 쓴다.

## 직접 해 볼 확인 (spec과 같음)

1. 상장사 1곳: 웹사이트·DART 두 섹션이 나오고, 모든 항목의 [출처]를 눌렀을 때 실제로 그 내용이 있다.
2. DART에 없는 소규모 SaaS 1곳: "DART 공시 대상이 아닌 회사"가 나오고 웹사이트 결과는 정상.
3. 잘못된 주소: "사이트를 읽지 못했습니다"와 이유가 나오고, 지어낸 내용이 없다.

## 자동 테스트 (개발용)

```
npm install
npm test
```

외부 사이트, Gemini, DART를 가짜 응답으로 바꿔 로직만 확인한다. 실제 키로 동작하는지는 위 수동 확인으로 본다.

## 파일

- `manifest.json` — 확장 설정 (Manifest V3, 사이드 패널)
- `sidepanel.html/js`, `styles.css` — 화면과 흐름
- `options.html/js` — 키 입력 화면
- `lib/core.js` — 순수 함수 (주소, 링크 고르기, DART 목록, 프롬프트, 결과 검증)
- `lib/services.js` — 네트워크 (웹사이트 읽기, Gemini, DART)
- `tests/` — Node 테스트
