# 중복 걸러내기 — P0 프로토타입

`docs/specs/홍하경-dedup.md`의 **P0**(규칙 기반, LLM 없음)만 만든 숙제용 프로토타입이다. 만든 사람: 홍하경.

새 리드 리스트와 과거 접촉 이력, 두 파일을 올리면 새 리드 각 행에 `판정`·`이유`·`겹친 기록` 컬럼을 붙인 엑셀을 내려받을 수 있다. 파일은 내 컴퓨터 안에서만 처리하고 외부로 보내지 않는다.

## 실행 방법 (Windows PowerShell)

Python 3.10 이상이 필요하다. 이 폴더에서 처음 한 번만:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

실행:

```powershell
.venv\Scripts\python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열린다. 끝낼 때는 터미널에서 `Ctrl+C`.

## 입력 파일

CSV(UTF-8 또는 엑셀이 저장하는 CP949)나 엑셀(.xlsx)을 받는다. 첫 줄 컬럼 이름이 아래와 같아야 한다.

| 파일 | 필요한 컬럼 |
|---|---|
| 새 리드 리스트 | `이름`, `회사`, `이메일`, `전화` |
| 과거 접촉 이력 | `이름`, `회사`, `이메일`, `전화`, `마지막 연락일` |

다른 컬럼이 더 있어도 되고, 결과 엑셀에 그대로 남는다.

## 판정 규칙

| 판정 | 기준 |
|---|---|
| 차단 | 이메일이나 전화번호가 같음 + 기준 기간(기본 90일) 안에 연락함 |
| 확인 필요 | 이름·회사는 같은데 이메일·전화가 다름 / 이메일·전화가 같은데 마지막 연락일이 없음 / 새 리스트 안에 같은 사람이 또 있음 |
| 주의 | 같은 회사의 다른 사람 / 기준 기간보다 오래된 접촉 이력 |
| 신규 | 위 어디에도 해당 안 됨 |

여러 기록과 겹치면 가장 심한 판정을 쓰고, `겹친 기록`에는 엑셀 행 번호와 함께 최대 3건을 보여준다. 자동으로 지우거나 합치지 않는다.

## 손으로 하는 확인

`samples/`에 스펙의 확인 세 가지가 파일 두 개씩 들어 있다. 기준일을 **2026-10-29**로 두고 하나씩 올린다.

| 확인 | 새 리드 | 접촉 이력 | 기대 판정 |
|---|---|---|---|
| 1 전화번호 형식만 다름 | `check1_new_leads.csv` | `check1_history.csv` | 차단 |
| 2 같은 회사의 다른 사람 | `check2_new_leads.csv` | `check2_history.csv` | 주의 |
| 3 이름과 회사만 같음 | `check3_new_leads.csv` | `check3_history.csv` | 확인 필요 |

같은 확인을 자동으로 돌리려면 (설치 필요 없음):

```powershell
python -m unittest -v
```

## 파일

- `dedup.py` — 정리·판정 규칙. 표준 라이브러리만 쓴다.
- `app.py` — Streamlit 화면.
- `tests/` — 손으로 하는 확인 세 가지와 규칙 테스트.
- `samples/` — 손으로 하는 확인용 CSV.
